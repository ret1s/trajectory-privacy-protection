The surveyed studies use different outputs and observation windows. A common
comparison needs the same time-stamped trip for scoring location estimates,
the public transcript each method would produce on that trip, and a POI
answer key for each local request. We generate paired route alternatives
on the road network in SUMO, using public geometry to select eligible trips
before scoring any defense. Replaying these trips across methods keeps the
targets and service conditions comparable while allowing each method its own
packet schedule. Related trips stay in one split to avoid training and testing
on the same route family.
