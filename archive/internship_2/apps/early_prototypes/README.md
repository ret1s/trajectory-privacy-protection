# Early web prototypes

These files predate the active benchmark dashboard and thesis simulator. They
are retained only to explain the implementation history.

- `simple_app.py` and `templates/simple_index.html`: first Flask route demo.
- `test_app.py`: local Flask installation smoke check, not a project test.

They use the archived Internship 2 mechanism. If they must be inspected at
runtime, install `requirements-legacy.txt` and invoke them from the repository
root with the root on `PYTHONPATH`; do not treat their outputs as thesis
benchmark evidence.
