# Bản chi tiết 18 trang

Bản PDF, HTML, script, ghi chú và nội dung của phiên bản 18 trang được giữ nguyên để tra cứu hoặc trả lời câu hỏi sâu hơn. Bản thuyết trình ngắn hiện hành nằm ở thư mục cha. `archive_release.json` ghi hash của năm file lưu. Các renderer và dữ liệu nguồn dùng chung vẫn nằm ở thư mục cha; không có mô hình hay benchmark mới được chạy khi rút gọn.
